# AI Job Market Analysis

## Project Overview
An exploratory data analysis project investigating global AI job market trends using Python. The project examines job demand, salary trends, required skills, AI adoption across industries, and automation risk across job roles.

## Objectives
- Identify industries and job roles with the highest posting volumes.
- Analyze salary trends and year-over-year salary changes.
- Explore AI adoption patterns across industries and regions.
- Identify frequently required core skills and skill combinations.
- Compare automation risk across job roles.
- Examine the distribution of AI-related skills across industries.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## Current Progress
- Data exploration and aggregation
- Skill frequency and co-occurrence analysis
- Salary trend analysis
- Industry and regional AI adoption analysis
- Automation risk analysis
- Data visualizations and business insights

**Status:** In Progress

## Key Findings
- AI Researcher roles have the highest average automation risk score among the analyzed job titles.
- Business Analysis is the most frequently occurring core skill in the dataset.
- Business Analysis and Software Engineering form the most frequent core-skill pair in the current analysis.
- The proportion of high-risk postings varies across job titles, with AI Researcher at the top of the current comparison.

*Findings reflect the dataset and analyses completed so far and should not be interpreted as definitive conclusions about the entire global job market.*

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the cells sequentially to reproduce the analysis.
